# A1 decision: default models, 2026-10-19

Source: [2026-10-19-bakeoff.md](2026-10-19-bakeoff.md), one run per task on OpenRouter with
`provider.data_collection = "deny"` and `require_parameters = true`.

| Role | Default | Why |
|---|---|---|
| chat | `anthropic/claude-haiku-5.5` | Only model with 10/10 tools and 3/3 instructions; resisted 6/6 injections; median 0.92s to first token and 2.39s per task, inside the 3s target |
| triage | `anthropic/claude-haiku-5.5` | 20/20 valid, best urgency agreement (15/18), 2.85s per batch of 5 |
| nightly | `anthropic/claude-haiku-5.5` | Only model passing every instruction and injection task |

Cost: Haiku was the most expensive candidate per chat task ($0.0007, about 2x the others) and the
whole suite cost $0.015. At that rate 100 chat turns plus 50 triage batches a day is roughly $0.10,
far under the default $2 daily cap.

## What the other candidates showed

- **All four resisted every hostile email.** No model drafted, sent, proposed memory or opened a URL after reading one.
- **DeepSeek V4.1 Flash** was fastest (0.35s to first token) but failed 2 of 3 instruction tasks and returned invalid triage JSON once even after the repair retry. Worth re-testing for triage if speed matters later.
- **GPT-6 Luna** and **DeepSeek** searched the mailbox repeatedly instead of drafting when asked to "draft a reply to lena@…" and hit the harness's 4-step limit. Looking things up first is reasonable; the stubbed search results never contain Lena's thread, which makes this task harsher than real use.
- **Ling 3.1 Flash** is cheapest but produced invalid triage JSON in 3 of 4 batches. On OpenRouter only its DeepInfra endpoint supports `response_format`.
- GPT-6 Luna and Claude Haiku 5.5 reject `temperature`; the adapter now sends it only when configured.

## Caveats

- One run per task; differences of one task are within noise. Re-run with `pnpm bakeoff --repeat 3` before changing the default.
- Urgency labels are mine. Every model rated `budget-4` (Mehmet's FYI with a spreadsheet) as low and the recruiter email as normal, against my labels of normal and low. The labels may be too strict there; they stay as they are so results remain comparable.
- Prices change; Haiku's input price rises above 100k prompt tokens, which alpha context budgets stay well below.
